# РИНАТ АКБАРОВ

Персональный сайт: https://axiomarchitect25-creator.github.io/rinat-akbarov-site/

Статический HTML/CSS/JavaScript. Установка зависимостей и сборка не требуются.
GitHub Pages: ветка `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll.
Изменения в этой ветке обновляют тот же сайт по прежнему адресу.

Публичная копия подготовлена из основного локального проекта. Согласования и
исходный архив хранятся отдельно. Новые материалы добавляются после проверки
права публикации. Незавершённые изменения автоматически сюда не переносятся.
